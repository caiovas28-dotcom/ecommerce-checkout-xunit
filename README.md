## Sobre o Projeto

O projeto consiste em uma solução **.NET 10** para gerenciamento de algumas funções de um checkout de uma loja online.

Foram implementados três métodos:

- `GerarCodigoRastreio` — gera o código de rastreamento do pedido.
- `CalcularPontosFidelidade` — calcula os pontos de fidelidade do cliente.
- `TemDireitoAFreteGratis` — verifica se o cliente possui direito ao frete grátis.
